# Original scripts

These files are preserved from the original EDSL example directory. The three
source hashes in `../behavioral_bias_run/protocol.json` refer to these copies.
They document the recorded experiment; use the scripts at the repository root
for the standalone quick start.

The original single-question filename and answer key still say France, although
the user had changed the question to Linda. The standalone example corrects
those names without changing the behavioral battery prompts.
